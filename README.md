# Smart-Precision-Agriculture-Monitoring-and-Automated-Irrigation-System-using-LPC2129-and-IoT
Developed a smart irrigation system using LPC2129 ARM7 to monitor soil moisture, temperature, humidity, and water levels. Automated pump control using sensor data and enabled real-time monitoring through LCD, EEPROM, SD card, and ThingSpeak cloud via ESP8266.
# Smart Agriculture Monitoring System

## Controller
LPC2129 ARM7

## Project Description
An intelligent agriculture monitoring and
automated irrigation system.

## Sensors Used
- Soil Moisture Sensor
- DHT22
- LM35
- Water Level Sensor
- Rain Sensor
- LDR
- PIR Sensor

## Communication Protocols
- UART
- I2C

## Features
- Real-time monitoring
- Automatic irrigation
- Temperature and humidity monitoring
- Water-level monitoring
